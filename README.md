# MultiPOS

MultiPOS is a secure, cloud-based multi-tenant Point of Sale (POS) system designed to modernize retail operations for Ghanaian SMEs.

Built with Next.js, Prisma, serverless PostgreSQL, and Paystack, the platform enables independent merchants to share a unified cloud infrastructure with strict tenant data isolation.

## Core capabilities

- Multi-branch inventory tracking
- Customizable role-based access control
- Mobile money clearing via Paystack
- Sales intelligence analytics
